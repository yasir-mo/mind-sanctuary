# 🍃 Sanctuary: Neurodivergent Decompression Lab

A zero-friction, sensory-crafted oasis designed for ADHD, hyperfocus recovery, and deep relaxation.

## 🌟 Key Features

1. **🌌 Interactive Calming Playgrounds (60 FPS Canvas)**:
   - **Bioluminescent Fluid & Sand**: Move cursor to produce glowing ripple harmonics and pentatonic singing bells.
   - **Cosmic Thought Dissolver**: Type any nagging bug, email, or worry to watch it shatter into physics-driven stardust and vanish into a cosmic vortex with Tibetan bowl resonance.
   - **Fractal Bonsai Grower**: Click anywhere to grow generative blossoming trees with wind sway and drifting petals.
   - **Tactile Bubble Wrap**: Endless pop sheet with randomized pitch synthesis and elastic haptics.

2. **🎵 Procedural Ambient Sound Synthesizer (Pure Web Audio API)**:
   - Zero audio assets / zero lag: 100% synthesized in real time.
   - Rain on glass, cozy lo-fi FM Rhodes piano, crackling hearth, ocean tides, forest wind, purring cat, and binaural waves (Theta 6Hz, Alpha 10Hz, Delta 2.5Hz).
   - 1-click sound presets (*Midnight Rain*, *Zen Temple*, *Cozy Fireplace*, *ADHD Drone*).

3. **🫁 HRV Breath & Coherence Pacer**:
   - Neuroscience-backed pacing: *Coherence 5.5s*, *Box Breathing (4-4-4-4)*, *4-7-8 Sleep*, and *Physiological Sigh*.
   - Hypnotic Sacred Geometry Lotus visualizer with synchronized ambient audio swells.

4. **📜 Mental Truce & Anti-Burnout Tools**:
   - **Official Permission Slip Generator**: Randomized witty, validating permission slips to turn off guilt and rest.
   - **Corporate Jargon & Stress Shredder**: Shred toxic phrases (*"per my last email"*) into digital confetti.
   - **2-Minute Micro-Step Unblocker**: Break executive dysfunction with zero-pressure micro-commitments.

5. **🎨 7 Handcrafted Aesthetic Themes**:
   - 🍵 Zen Garden
   - 🌌 Cyberpunk Chillhop
   - 💾 Windows 98 Retro
   - 🎀 Coquette & Slay
   - 🏢 Corporate Burnout Rehab
   - 🧠 Brainrot Detox Lounge
   - ☕ Lo-Fi Studio Warmth

## 🚀 How to Run

### Option 1: Python Launcher (Recommended)
```bash
python launch.py
```
Starts a quiet local server at `http://localhost:8042` and opens your browser.

### Option 2: Direct File Open
Simply double-click `index.html` to open it in any modern browser!

## ⌨️ Hotkeys
- `Space`: Instant Mute / Unmute
- `1` - `4`: Quick-switch Sanctuary spaces
- `T`: Cycle through aesthetic themes
